## How to Use

### For Students
1. Open `index.html` in any modern browser
2. Navigate using the top menu
3. Choose Data Science or Cybersecurity path
4. Click on any topic to start learning
5. Complete exercises and track progress

### For Developers
1. Clone or download the project
2. No build process required
3. All dependencies via CDN
4. Edit HTML/CSS/JS directly
5. Test in browser immediately

### For Content Creators
1. Use `content/datascience/python.html` as template
2. Copy structure for new pages
3. Replace content with your material
4. Add to navigation dropdowns
5. Follow established patterns
