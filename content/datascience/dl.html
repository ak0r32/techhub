What is Deep Learning?

Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple layers (hence "deep") to learn hierarchical representations of data. It has revolutionized AI by achieving human-level performance in tasks like image recognition, natural language processing, and game playing.

Why Deep Learning?

  • Automatic Feature Learning: No need for manual feature engineering
  • Handles Complex Data: Excels with images, audio, text, and video
  • Scalability: Performance improves with more data and compute
  • State-of-the-Art Results: Best performance in computer vision, NLP, and more
  • End-to-End Learning: Learn directly from raw data to predictions
The Deep Learning Revolution:

Since 2012, deep learning has transformed AI with breakthroughs like ImageNet classification, AlphaGo defeating world champions, GPT language models, and self-driving cars.

Neural Networks Basics

Artificial Neural Networks (ANNs) are inspired by biological neurons in the human brain. They consist of interconnected nodes (neurons) organized in layers.

Network Structure

  • Input Layer: Receives the raw data/features
  • Hidden Layers: Process and transform the data
  • Output Layer: Produces the final prediction

Simple Neural Network in PyTorch

import torch
import torch.nn as nn

class SimpleNN(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(SimpleNN, self).__init__()
        self.layer1 = nn.Linear(input_size, hidden_size)
        self.relu = nn.ReLU()
        self.layer2 = nn.Linear(hidden_size, output_size)
        self.sigmoid = nn.Sigmoid()
    
    def forward(self, x):
        x = self.layer1(x)
        x = self.relu(x)
        x = self.layer2(x)
        x = self.sigmoid(x)
        return x

# Create model
model = SimpleNN(input_size=10, hidden_size=20, output_size=1)
print(model)

Activation Functions

  • ReLU: f(x) = max(0, x) - Most commonly used
  • Sigmoid: f(x) = 1/(1+e^-x) - Output between 0 and 1
  • Tanh: f(x) = tanh(x) - Output between -1 and 1
  • Softmax: For multi-class classification

Convolutional Neural Networks (CNNs)

CNNs are the go-to architecture for computer vision tasks. They use convolutional layers to automatically learn spatial hierarchies of features.

Key Components

  • Convolutional Layers: Apply filters to detect features (edges, textures, patterns)
  • Pooling Layers: Reduce spatial dimensions while retaining important information
  • Fully Connected Layers: Make final classification decisions

CNN for Image Classification

import torch.nn as nn

class CNN(nn.Module):
    def __init__(self):
        super(CNN, self).__init__()
        # Convolutional layers
        self.conv1 = nn.Conv2d(3, 32, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.conv3 = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        
        # Pooling layer
        self.pool = nn.MaxPool2d(2, 2)
        
        # Fully connected layers
        self.fc1 = nn.Linear(128 * 4 * 4, 512)
        self.fc2 = nn.Linear(512, 10)  # 10 classes
        
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(0.5)
    
    def forward(self, x):
        # Convolutional layers with pooling
        x = self.pool(self.relu(self.conv1(x)))
        x = self.pool(self.relu(self.conv2(x)))
        x = self.pool(self.relu(self.conv3(x)))
        
        # Flatten
        x = x.view(-1, 128 * 4 * 4)
        
        # Fully connected layers
        x = self.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)
        return x

model = CNN()

Recurrent Neural Networks (RNNs)

RNNs process sequential data by maintaining hidden states that capture information from previous time steps.

LSTM (Long Short-Term Memory)

LSTMs are a special kind of RNN designed to handle long-term dependencies and avoid the vanishing gradient problem.

LSTM for Sequence Prediction

class LSTMModel(nn.Module):
    def __init__(self, input_size, hidden_size, num_layers, output_size):
        super(LSTMModel, self).__init__()
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        
        # LSTM layer
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers, 
                           batch_first=True, dropout=0.2)
        
        # Fully connected layer
        self.fc = nn.Linear(hidden_size, output_size)
    
    def forward(self, x):
        # Initialize hidden and cell states
        h0 = torch.zeros(self.num_layers, x.size(0), self.hidden_size)
        c0 = torch.zeros(self.num_layers, x.size(0), self.hidden_size)
        
        # Forward propagate LSTM
        out, _ = self.lstm(x, (h0, c0))
        
        # Get output from last time step
        out = self.fc(out[:, -1, :])
        return out

model = LSTMModel(input_size=10, hidden_size=128, num_layers=2, output_size=1)

Training Deep Neural Networks

The Training Process

  1. Forward Pass: Input data flows through the network to produce predictions
  2. Loss Calculation: Measure the difference between predictions and actual labels
  3. Backward Pass: Calculate gradients using backpropagation
  4. Weight Update: Adjust weights using optimization algorithm (SGD, Adam)
  5. Repeat: Iterate for multiple epochs

Complete Training Loop

Optimization Techniques

  • Batch Normalization: Normalize layer inputs for faster training
  • Dropout: Randomly drop neurons to prevent overfitting
  • Learning Rate Scheduling: Adjust learning rate during training
  • Data Augmentation: Create variations of training data
  • Transfer Learning: Use pre-trained models as starting point
