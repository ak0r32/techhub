Introduction to Python

Python is a high-level, interpreted programming language known for its simplicity and readability. It's widely used in Data Science, Machine Learning, Web Development, and Automation.

Why Python for Data Science?

Python has become the language of choice for data scientists due to:

  • Extensive libraries (NumPy, Pandas, SciPy, Scikit-learn)
  • Simple syntax and easy learning curve
  • Strong community support
  • Excellent visualization libraries (Matplotlib, Seaborn, Plotly)
  • Integration with big data tools

Your First Python Program

# Simple Python program
print("Hello, TechLearn Hub!")

# Basic arithmetic
x = 10
y = 20
sum = x + y
print(f"The sum of {x} and {y} is {sum}")

# Python is dynamically typed
message = "Learning Python for Data Science"
print(message)

Python Installation

To get started with Python:

  1. Download Python from python.org (version 3.8 or higher)
  2. Install Python with PATH environment variable enabled
  3. Verify installation: python --version
  4. Install an IDE (VS Code, PyCharm) or use Jupyter Notebook
Exercise 1.1: Python Setup

Install Python on your system and run a simple "Hello World" program. Verify that you can execute Python code from your terminal or IDE.

Challenge: Create a program that prints your name and a fun fact about Data Science.

Key Python Features

Some of Python's most important features for Data Science:

  • Interpreted Language: No compilation needed
  • Dynamically Typed: No need to declare variable types
  • Object-Oriented: Supports classes and objects
  • Extensive Standard Library: Built-in modules for various tasks
  • Cross-platform: Runs on Windows, macOS, Linux
Exercise 1.2: Interactive Shell Practice

  1. Calculate: (15 * 3) / 2 + 7
  2. Create a variable with your favorite number
