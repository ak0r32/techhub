# Cybersecurity Topics - Complete Reference

## All Cybersecurity Files in Your Content Folder

### 1. fundamentals.html - Cybersecurity Fundamentals
**Icon:** `fas fa-shield-alt`
**Description:** Introduction to cybersecurity concepts, principles, and best practices. Covers the CIA triad (Confidentiality, Integrity, Availability), security policies, and foundational knowledge for all cybersecurity professionals.

### 2. network.html - Network Security
**Icon:** `fas fa-network-wired`
**Description:** Focuses on securing computer networks from unauthorized access, attacks, and misuse. Topics include firewalls, VPNs, intrusion detection systems, network protocols, and securing network infrastructure.

### 3. cryptography.html - Cryptography
**Icon:** `fas fa-lock`
**Description:** Study of secure communication techniques. Covers encryption algorithms (AES, RSA), digital signatures, hash functions, public-key infrastructure, and cryptographic protocols used to protect data.

### 4. ethics.html - Ethical Hacking
**Icon:** `fas fa-user-secret`
**Description:** Legal and authorized practice of bypassing system security to identify potential vulnerabilities. Covers penetration testing methodologies, vulnerability assessment, and responsible disclosure.

### 5. forensics.html - Digital Forensics
**Icon:** `fas fa-search`
**Description:** Process of identifying, preserving, analyzing, and presenting digital evidence. Includes incident investigation, data recovery, chain of custody, and forensic tools and techniques.

### 6. incident.html - Incident Response
**Icon:** `fas fa-exclamation-triangle`
**Description:** Structured approach to handling security incidents. Covers incident detection, containment, eradication, recovery, and post-incident analysis (the incident response lifecycle).

### 7. malware.html - Malware Analysis
**Icon:** `fas fa-bug`
**Description:** Study of malicious software including viruses, worms, trojans, ransomware, and spyware. Covers static and dynamic analysis, sandboxing, and malware reverse engineering.

### 8. soc.html - SOC Operations
**Icon:** `fas fa-eye`
**Description:** Security Operations Center management and operations. Covers security monitoring, alert triage, incident handling workflows, and 24/7 security surveillance best practices.

### 9. siem.html - SIEM Tools
**Icon:** `fas fa-chart-line`
**Description:** Security Information and Event Management systems. Covers log collection, correlation, analysis, and reporting using SIEM platforms like Splunk, QRadar, or ELK Stack.

### 10. pentest.html - Penetration Testing
**Icon:** `fas fa-crosshairs`
**Description:** Simulated cyber attacks against systems to identify vulnerabilities. Covers testing methodologies (OWASP, PTES), tools (Metasploit, Burp Suite), and reporting findings.

### 11. webapp.html - Web Application Security
**Icon:** `fas fa-globe`
**Description:** Securing web applications from common vulnerabilities. Covers OWASP Top 10, SQL injection, XSS, CSRF, authentication, and session management security.

### 12. mobile.html - Mobile Security
**Icon:** `fas fa-mobile-alt`
**Description:** Security of mobile devices and applications. Covers mobile app security, device management, mobile malware, and securing iOS and Android platforms.

### 13. cloud.html - Cloud Security
**Icon:** `fas fa-cloud`
**Description:** Security of cloud computing environments. Covers AWS, Azure, GCP security, cloud architecture security, identity and access management, and cloud compliance.

### 14. threat.html - Threat Intelligence
**Icon:** `fas fa-skull-crossbones`
**Description:** Gathering and analyzing information about potential threats. Covers threat feeds, indicators of compromise (IOCs), threat actor profiling, and proactive threat hunting.

### 15. iot.html - IoT Security
**Icon:** `fas fa-microchip`
**Description:** Security of Internet of Things devices. Covers securing smart devices, IoT protocols, firmware security, and protecting IoT networks from attacks.

### 16. compliance.html - Compliance
**Icon:** `fas fa-balance-scale`
**Description:** Adhering to regulatory requirements and standards. Covers GDPR, HIPAA, PCI-DSS, SOC 2, ISO 27001, and other compliance frameworks.

### 17. Rodemap.html - Roadmap
**Icon:** `fas fa-road`
**Description:** Learning path and career roadmap for cybersecurity professionals. Covers skill progression, certifications, career paths, and recommended learning order.
